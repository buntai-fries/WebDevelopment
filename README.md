## 💻 How to Run the Back-End Projects Locally

Starting from Section 20, projects require a local server and Node packages to run. To test my backend code on your machine:

1. Clone this repository:

```bash
  git clone [https://github.com/buntai-fries/WebDevelopment.git]
```

2. Navigate to the specific project directory:

```bash
  cd [Project-Folder-Name]
```

3. Install the required Node dependencies:

```bash
  npm install [Module-Name]
```

4. Start the local development server:

```bash
node index.js
```

5. Open your browser and navigate to

```bash
  http://localhost:3000
```

OR

```bash
  http://localhost:3000
```

## 🧠 Key Takeaways

### Read the Docs:

Learning to navigate MDN Web Docs, Express JS docs, and API documentation is a superpower. Syntax changes, but the core concepts don't.

### Console.log is life:

Breaking down complex bugs by checking the flow of data at every step saves hours of frustration.

### Security Matters:

Never hardcode API keys. Environment variables (dotenv) and .gitignore are non-negotiable for backend projects.
